# 脚本参数与交互规范（参考）

本文是 `AGENTS.md` 的详细参考，给出判断标准、代码示例和检查清单。

## 1. 动态参数放在顶部，并且逐个注释

脚本中需要用户根据自己的环境填写或修改的参数，必须集中放在文件顶部容易看到的位置，不能散落在脚本中间。

动态参数包括但不限于：

- 安装目录、数据目录、配置文件路径
- 端口、IP、域名、镜像地址
- 账号、数据库名、服务名
- 版本号、包名、路径前缀

要求：

- 顶部使用醒目的分隔线标出「用户配置区」
- 每个参数单独一行，变量名清晰
- 每个参数上方必须有注释，说明用途，并给出示例值
- 注释使用中文，与仓库现有脚本风格保持一致

## 2. 固定选项使用交互式选择

如果某个选择只有有限个固定选项（例如 MySQL 版本、安装方式、CPU 架构、是否安装某组件），不要在顶部写成需要用户先编辑的变量，而应做成交互式菜单。

要求：

- 直接列出编号菜单，用 `set /p`（Windows）或 `read`（Linux）读取用户输入
- 用户双击脚本即可完成选择，不需要先用编辑器改脚本
- 输入非法时给出提示并重新选择，或给出默认值
- 固定选项通过交互式选择后，再映射为脚本内部变量

## 3. 判断标准

| 情况 | 做法 |
|------|------|
| 值随用户环境变化，无法预先枚举 | 顶部配置区，逐项注释 |
| 只有有限个固定选项 | 交互式编号菜单 |
| 既有固定选项又有动态值 | 固定选项用交互式菜单，动态值仍放顶部并注释 |
| 参数有合理默认值 | 使用默认值，并在注释中说明如何修改 |

## 4. 示例

Windows 脚本（动态参数）：

```bat
@echo off
rem ============================================================================
rem 用户配置区：请按自己的环境修改以下参数
rem ============================================================================
rem MySQL 安装目录（示例：C:\Program Files\MySQL\MySQL Server 8.0）
set "MYSQL_HOME=C:\Program Files\MySQL\MySQL Server 8.0"

rem my.ini 配置文件完整路径（示例：C:\ProgramData\MySQL\MySQL Server 8.0\my.ini）
set "MY_INI=C:\ProgramData\MySQL\MySQL Server 8.0\my.ini"

rem Windows 服务名称（示例：MySQL80）
set "MYSQL_SERVICE=MySQL80"
```

Windows 脚本（固定选项交互式选择）：

```bat
echo 请选择要安装的 MySQL 版本：
echo   [1] MySQL 8.0
echo   [2] MySQL 5.7
set /p CHOICE=请输入序号:
if "%CHOICE%"=="1" set "MYSQL_VERSION=8.0"
if "%CHOICE%"=="2" set "MYSQL_VERSION=5.7"
```

Linux 脚本（动态参数）：

```bash
#!/usr/bin/env bash
# ============================================================================
# 用户配置区：请按自己的环境修改以下参数
# ============================================================================
# 安装目录（示例：/usr/local/mysql）
MYSQL_HOME="/usr/local/mysql"

# 服务名称（示例：mysqld）
MYSQL_SERVICE="mysqld"
```

Linux 脚本（固定选项交互式选择）：

```bash
echo "请选择要安装的 MySQL 版本："
echo "  [1] MySQL 8.0"
echo "  [2] MySQL 5.7"
read -rp "请输入序号: " choice
case "$choice" in
    1) MYSQL_VERSION="8.0" ;;
    2) MYSQL_VERSION="5.7" ;;
    *) echo "无效选择"; exit 1 ;;
esac
```

## 5. 检查清单

新增或修改脚本后，逐项确认：

- [ ] 需要用户修改的参数是否都在文件顶部
- [ ] 顶部的每个参数是否都有中文注释和示例
- [ ] 固定选项是否做成了交互式选择，双击即可运行
- [ ] 脚本是否不再要求用户先编辑文件才能使用
- [ ] 参数和菜单的默认值、非法输入是否已处理
