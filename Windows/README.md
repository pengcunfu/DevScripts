# Windows 实用工具脚本集合

一组实用的 Windows 批处理脚本，用于系统配置和开发环境管理。

- [开发工具](#开发工具)

## 📦 包管理器工具

### `pip_mirror_config.bat`
**PIP 镜像源配置工具**

配置 PIP 包管理器的镜像源，加速国内下载。

**支持的镜像源：**
- 豆瓣源
- 官方源 (PyPI)
- 华为云镜像
- 清华大学镜像
- 阿里云镜像

**使用方法：** 双击运行，选择所需的镜像源即可

### `npm_mirror_config.bat`
**NPM 镜像源配置工具**

配置 NPM 包管理器的注册表镜像。

**功能特性：**
- 切换淘宝、官方、腾讯、华为镜像
- 查看当前注册表配置
- 测试镜像速度

**使用方法：** 双击运行，选择所需操作

## 🛠️ 系统工具

### `refresh_icon_cache.bat`
**Windows 图标缓存刷新工具**

清除并重建 Windows 图标缓存，修复图标显示问题。

**脚本功能：**
- 关闭 Windows 资源管理器
- 清除图标缓存数据库
- 清除系统托盘图标缓存
- 重启 Windows 资源管理器

**使用方法：** 右键"以管理员身份运行"，资源管理器会自动重启

### `fix_office_preview.bat`
**Office 预览窗格修复工具**

修复 Windows 资源管理器中 Office 文件预览功能失效的问题。

**支持的文件类型：**
- Word (.doc, .docx)
- Excel (.xls, .xlsx)
- PowerPoint (.ppt, .pptx)

**使用方法：** 右键"以管理员身份运行"，根据提示重启资源管理器

### `win11_context_menu.bat`
**Windows 11 右键菜单切换工具**

在 Windows 11 现代右键菜单和 Windows 10 经典样式之间切换。

**选项：**
1. 禁用现代菜单（显示"显示更多选项"，Win10 样式）
2. 恢复现代菜单（Win11 默认）

**使用方法：** 右键"以管理员身份运行"，资源管理器会自动重启

### `win11_menu_switcher.bat`
**Windows 11 开始菜单切换工具**

在 Windows 11 和 Windows 10 开始菜单样式之间切换。

**选项：**
1. Win11 默认菜单
2. Win10 经典菜单

**使用方法：** 右键"以管理员身份运行"，资源管理器会自动重启

### `wechat_multi_instance.bat`
**微信多开启动器**

同时启动多个微信实例。

**⚠️ 需要配置路径：**
编辑脚本，修改微信安装路径：
```batch
cd "D:\App\Common\WeChat"
```

**使用方法：** 双击即可启动两个微信窗口

## 📁 右键菜单工具

### `notepad_context_menu.bat`
**Notepad++ 右键菜单管理器**

添加或移除 Notepad++ 到 Windows 右键菜单。

**功能特性：**
- 为所有文件添加"用 Notepad++ 打开"选项
- 自动请求管理员权限
- 完整清理菜单项

**使用方法：** 右键"以管理员身份运行"，选择添加或移除

### `vscode_context_menu.bat`
**VSCode 右键菜单管理器**

添加或移除 VSCode"通过 Code 打开"文件夹的右键菜单选项。

**⚠️ 需要配置路径：**
编辑脚本，修改 VSCode 路径：
```batch
set "menuPath=D:\Peng\App\DevApp\Microsoft VS Code\Code.exe"
```

**功能特性：**
- 添加到文件夹右键菜单
- 添加到文件夹背景右键菜单（文件夹空白处）
- 可自定义菜单名称

**使用方法：** 右键"以管理员身份运行"，选择添加或移除

### `cmd_context_menu.bat`
**CMD 右键菜单工具**

添加命令提示符选项到 Windows 右键菜单。

## 💻 开发工具

### `php_version_switcher.bat`
**PHP 版本切换器**

通过修改系统 PATH 环境变量，在多个 PHP 安装版本之间切换。

**⚠️ 需要配置路径：**
编辑脚本，修改 PHP 基础路径：
```batch
set "phpBasePath=D:\Peng\App\DevApp\php-"
```

**支持的版本：**
- PHP 7.4
- PHP 8.0
- PHP 8.1
- PHP 8.2
- PHP 8.3

**使用方法：** 右键"以管理员身份运行"，选择所需的 PHP 版本

### `jdk_version_switcher.cmd`
**JDK 版本切换器**

通过修改系统 PATH 环境变量，在多个 JDK 安装版本之间切换。

**⚠️ 需要配置路径：**
编辑脚本，修改 JDK 基础路径：
```batch
set "jdkBasePath=D:\Peng\App\DevApp\jdk-"
```

**支持的版本：**
- JDK 8
- JDK 11
- JDK 17

**使用方法：** 右键"以管理员身份运行"，选择所需的 JDK 版本

## 📝 使用说明

### 管理员权限
大多数脚本需要管理员权限来修改系统设置：
- 右键点击脚本
- 选择"以管理员身份运行"
- 或从提升权限的命令提示符运行

### 路径配置
标记有 ⚠️ 的脚本需要手动配置路径：
1. 右键点击脚本，选择"编辑"
2. 修改指定路径以匹配你的安装位置
3. 保存文件
4. 运行脚本

### 文件编码
所有脚本使用标准 ASCII/英文编码，避免在不同 Windows 系统上出现字符编码问题。
